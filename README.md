# P-mng Goscrobble

## How do I install these formulae?

`brew install p-mng/goscrobble/<formula>`

Or `brew tap p-mng/goscrobble` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "p-mng/goscrobble"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
