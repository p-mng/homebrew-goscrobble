# goscrobble homebrew

## How do I install these formulae?

`brew install p-mng/goscrobble/goscrobble`

Or `brew tap p-mng/goscrobble` and then `brew install goscrobble`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "p-mng/goscrobble"
brew "goscrobble"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
